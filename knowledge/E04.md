# E04 信息与编码

别名：编码、二进制、信息、01、计算机编码、海报四号
形式：海报

## 讲解

这张海报讲的是信息怎么变成机器能读懂的样子。计算机内部只认识两种状态：有电和没电，我们用 1 和 0 表示，这就是二进制。每一个 0 或 1 叫做一个“比特”，8 个比特组成一个“字节”。

海报从左到右是一条完整的通信过程：先有一条消息，比如 HELLO；然后编码，把每个字母按规则变成一串 0 和 1；这些 0 和 1 变成电信号或无线电波传出去；接收方再解码，把信号还原成文字。海报右边的例子里，01001000 按照 ASCII 编码规则对应的就是大写字母 H。

我们今天发微信、看视频、打电话，背后都是同样的原理，只是编码方式更复杂，还加入了压缩和纠错，让信息传得更快、更可靠。

## 常见问题

- 问：什么是二进制？ 答：只用 0 和 1 两个数字表示信息的计数方法，计算机就用它。
- 问：01001000 是什么？ 答：按 ASCII 编码，它代表大写字母 H。
- 问：比特和字节是什么关系？ 答：8 个比特组成 1 个字节。
- 问：编码和解码是什么？ 答：编码是把信息变成信号，解码是把信号还原成信息。
- 问：为什么计算机用二进制？ 答：电路只要区分通和断两种状态，简单、稳定、不容易出错。
- 问：汉字怎么编码？ 答：常用 UTF-8 等编码，一个汉字一般占 3 个字节。
- 问：适合谁看？ 答：适合对计算机和通信感兴趣的观众，初中以上更容易理解。
